# 日程同步 · 局域网双端

一个跑在你自己电脑上的网页版可视化日程 / 待办程序。
手机（小米 14）和电脑连同一个 Wi-Fi，打开同一个地址，**任何一端改动，另一端自动更新**。

- 月 / 周 / 日 三种视图，点一下就能新建
- 待办清单：优先级、截止日期、勾选完成
- 到点提醒：弹窗 + 声音 + 震动
- 数据只存在你自己的电脑里，不经过任何云服务
- 可"添加到桌面"，用起来和 App 一样

---

## 一、快速开始

### Windows

1. 安装 Python 3（<https://www.python.org/downloads/>，安装时勾选 **Add python.exe to PATH**）
2. 双击 **`启动服务-Windows.bat`**
3. 控制台会打印两个地址，记下"手机访问"那一行

### macOS / Linux

```bash
chmod +x 启动服务-Mac-Linux.sh
./启动服务-Mac-Linux.sh
```

### 打开程序

- 电脑：浏览器打开 <http://localhost:8765>
- 手机：连同一个 Wi-Fi，浏览器打开控制台里打印的 `http://192.168.x.x:8765`
  - 也可以直接在电脑上点右上角 **齿轮 → 手机连接地址**，用手机扫二维码，一步到位
- 手机上建议：浏览器菜单 → **添加到主屏幕**，之后从桌面图标打开

> 端口默认 8765，如果被占用会自动往后找；也可以 `python server.py -p 9000` 指定。

## 二、双端同步是怎么工作的

```
手机浏览器  ──┐                    ┌── data/data.json（电脑上的唯一数据源）
              ├──► server.py ◄─────┤
电脑浏览器  ──┘   局域网 8765        └── SSE 长连接：一有改动立刻推给所有页面
```

- 任何一端保存后，先把这条记录写到电脑上的 `data/data.json`
- 服务端把数据版本号通过 SSE 推给所有打开着的页面，页面收到后自动拉最新数据（通常 1 秒内）
- **条目级合并**：手机在改日程 A、电脑在改日程 B，两边的改动都会保留
- 同一条被两端同时修改时，以最后修改时间为准
- 电脑关机 / 手机离开 Wi-Fi 时，页面自动进入"离线模式"，改动暂存在本机；恢复连接后自动合并回传，不会丢

## 三、数据与备份

| 内容 | 位置 |
| --- | --- |
| 全部数据 | `data/data.json` |
| 每日快照（保留最近 30 天） | `data/backups/backup-YYYY-MM-DD.json` |

> 换电脑时，把整个文件夹拷过去即可，`data/data.json` 就是全部数据。

## 四、常见问题

**1. 手机打不开地址**

- 确认手机和电脑在**同一个 Wi-Fi**（访客网络、5G/2.4G 不同频段有时是不同网段）
- Windows 第一次运行会弹防火墙提示，必须点"允许访问"；若已点过拒绝，到「Windows 安全中心 → 防火墙 → 允许应用通过防火墙」里放行 Python
- 路由器开启「AP 隔离 / 无线隔离」会阻止设备互访，需要在路由器里关掉
- 电脑 IP 会变：建议在路由器里给电脑绑定固定 IP（DHCP 保留），或每次看控制台打印的地址

**2. 提醒不响 / 手机锁屏收不到**

- 浏览器通知只在页面开着时可靠；手机锁屏后浏览器会冻结页面，这是系统限制
- 重要日程建议在**设置 → 导出 .ics**，用小米日历导入，获得系统闹钟级别的锁屏提醒
- 电脑上点「开启浏览器通知」并允许，页面在前台时能弹系统通知

**3. 电脑关机了手机还能用吗？**

能打开（如果页面已缓存），但会显示"离线模式"。数据源在电脑上，电脑开机并启动服务后自动同步。

**4. 能多台电脑 / 多部手机一起用吗？**

可以，任何设备打开同一个局域网地址都是同一份数据。

**5. 开机自动启动**

- Windows：把 `启动服务-Windows.bat` 的快捷方式放进「启动」文件夹（`Win + R` 输入 `shell:startup`）
- macOS：用「系统设置 → 通用 → 登录项」添加脚本
- Linux：用 systemd 或 `@reboot` crontab


## 六、安全说明

服务只在局域网内监听，没有密码保护——同一个 Wi-Fi 下的设备理论上都能访问。家里、宿舍自用没问题；**不要在公共 Wi-Fi 下开启**。

## 七、关于 GitHub Pages

同一套网页也可以发布到 GitHub Pages（https 地址）。但注意：**https 页面不能访问 http 的局域网服务**（浏览器混合内容限制），所以 Pages 版只能显示本机缓存、处于离线模式。它适合当代码备份 / 在外地只看不改。日常请用局域网地址。
